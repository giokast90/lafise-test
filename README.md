## Description

lafise-test is a mobile application that enables users to perform online money transfers. It provides functionalities
for navigating through different tabs, managing financial transactions, and confirming transfers with an easy-to-use
interface.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/giokast90/lafise-test.git
   cd lafise-test
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npx expo start
   ```
4. Launch the project in a simulator or physical device. For mobile development, ensure Expo CLI or equivalent tooling
   is installed.
5. Use your camera to scan the QR code or press the "i" key to open the iOS simulator.

## Usage

- The app consists of multiple tabs for different functionalities: Home, Operations, and Products.
- Users can initiate money transfers and confirm their transactions via a simple and secure workflow.
- It supports features such as form validation and responsive feedback during operations.

## Features

- **Tabbed navigation**: Navigate through Home, Operations, and Products screens.
- **Transfer money**: Enter recipient account details and transfer amount.
- **Transaction confirmation**: Verify transfer details before submission.
- **Success messages**: Get notified upon successful transactions.
